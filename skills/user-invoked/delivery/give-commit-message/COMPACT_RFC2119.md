Main source - [RFC2119](https://www.ietf.org/rfc/rfc2119.txt)

The imperatives are keywords to signify the severity of the level of requirements. 
It could be useful to add these as a reference for an agent somewhere, like existing documentation or documentation creating skills.

# MUST | REQUIRED | SHALL
definition is an absolute requirement of the specification.

# MUST NOT | SHALL NOT
definition is an absolute prohibition of the specification.

# SHOULD | RECOMMENDED
there may exist valid reasons **in particular circumstances** to ignore a
particular item, but the full implications must be understood and
carefully weighed before choosing a different course.

# SHOULD NOT | NOT RECOMMENDED
there may exist valid reasons in particular circumstances when the
particular behavior is acceptable or even useful, but the full
implications should be understood and the case carefully weighed
before implementing any behavior described with this label.

# MAY | OPTIONAL
that item is truly optional, with all consequences of such decision.
An implementation which does not include a particular option MUST be
prepared to interoperate with another implementation which does
include the option
