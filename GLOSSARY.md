# Repository Glossary

This root glossary contains terms specific to maintaining this source
repository. Canonical project-agnostic workflow and architecture terms live in
[`shared/AGENTIC_GLOSSARY.md`](shared/AGENTIC_GLOSSARY.md).

## Agentic coding repo

This repository: the source and distribution mechanism for reusable agent
guidelines, skills, and shared terminology.

## Managed asset

A file or directory owned by this repository's installer and replaced on
update. Installed managed assets live only under a target project's `.agentic/`
directory.

## Source asset

A canonical reusable file under `shared/` or a reusable skill under `skills/`
from which an installed managed asset is produced.
